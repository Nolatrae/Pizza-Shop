# Frontend приложение для пиццерии

- Разработка полноценного фронтенд-приложения на ReactJS.
- Создание компонентов, страниц, сортировки, поиск, пагинации, фильтрации, popup-окна и тд
- Взаимодействие с серверной частью и отправлять запросы на бэкенд.
- Разработка навигации по странице без перезагрузки.
- Создание глобальное хранилище данных для всего приложения.
- Работа с LocalStorage для хранения настроек сайта.
- Использование Lazy Loading и debounce для оптимизации поиска.

## 🛠 Технологии

- **ReactJS 18**
- **TypeScript**
- **Redux Toolkit** (хранение данных / пицц)
- **React Router v6** (навигация)
- **Axios + Fetch** (отправка запросов на бэкенд)
- React Hooks (хуки)
- Prettier (форматирование кода)
- CSS-Modules / SCSS (стилизация)
- React Content Loader (скелетон)
- React Pagination (пагинация)
- Lodash.Debounce
- Code Splitting, React Loadable, useWhyDidYouUpdate

### Подробнее о технологиях

- [**TypeScript**](https://www.typescriptlang.org/) — для написания более грамотного JavaScript-кода с автоматической документацией и меньшим количеством багов.
- [**Redux Toolkit**](https://redux-toolkit.js.org/) — создание глобального хранилища данных для обмена информацией между компонентами.
- [**React Router v6**](https://reactrouter.com/docs/en/v6/getting-started/overview) — создание навигации без перезагрузок страницы.
- [**Axios**](https://github.com/axios/axios) — взаимодействие с серверной частью для отправки и получения данных.
- [**React Hooks**](https://ru.reactjs.org/docs/hooks-intro.html) — готовые функции для решения задач хранения данных и оптимизации.
- [**Prettier**](https://prettier.io/) — автоматическое выравнивание кода для улучшения читабельности.
- [**SCSS**](https://sass-scss.ru/) — расширенные возможности CSS с переменными и циклами.
- [**CSS-Modules**](https://github.com/css-modules/css-modules) — инкапсуляция CSS-классов с использованием CSS-модулей.
- [**Lodash**](https://lodash.com/docs) — набор готовых функций для различных задач.
